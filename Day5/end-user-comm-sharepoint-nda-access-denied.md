# End-User Communication — Copilot Cannot Access NDA in SharePoint

**Date:** 2026-08-12  
**Ticket:** Copilot SharePoint NDA access  
**To:** Affected User  
**From:** DWP Service Desk  
**Subject:** Copilot Access Issue — SharePoint NDA

Hi,

Thank you for reporting this. Copilot can only summarise documents that your account already has permission to open in SharePoint.

**What has likely happened?**  
The NDA is probably stored in a folder that your account has not been granted access to yet, or the document library has not finished indexing the file for Copilot. Because you have not opened that folder before, this may be an access control issue rather than a problem with the document itself.

**What are we doing about it?**  
We will check whether your account has the correct SharePoint permissions for that folder and confirm whether the document is available for Copilot to use.

**What can you do right now?**

1. **Try opening the NDA directly in SharePoint** — if you cannot open it, that confirms the folder or document permissions need to be reviewed.
2. **Check whether a colleague can open the same file** — this helps us confirm whether the issue is limited to your account.
3. **Let us know the exact file name and folder path** — that will help us check the correct location quickly.

**What happens next?**  
Once access is confirmed or corrected, Copilot should be able to summarise the document as expected. If you need the NDA reviewed urgently, please contact the Service Desk on the usual route and quote the ticket details.
