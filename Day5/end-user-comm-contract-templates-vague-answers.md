# End-User Communication — Copilot Answers About Contract Templates Are Too Generic

**To:** Affected User  
**From:** DWP Service Desk  
**Subject:** Copilot Response Quality in Contract Templates Library

Hi,

Thank you for reporting this. Copilot works best when it can read clear, text-based documents and when the question points it to a specific file or clause.

**What has likely happened?**  
The contract templates library may contain documents that are not yet fully indexed, or the files may be in a format that is difficult for Copilot to interpret. If the prompt is very broad, Copilot may also return a general answer instead of a clause-specific one.

**What are we doing about it?**  
We will check the library format, indexing status, and access to the source documents so we can confirm why the answers are so generic.

**What can you try right now?**

1. **Ask about a specific template or clause** — for example, name the document and quote the clause number if you have it.
2. **Open the source document directly** — this confirms the content is available and readable.
3. **Check whether the file is a scanned PDF or image** — those often produce weaker Copilot results than Word documents or text-based PDFs.

**What happens next?**  
If the library is still indexing or the file format is limiting Copilot, we will confirm the issue and advise the best workaround. If you need help with a specific clause urgently, please contact the Service Desk on the usual route and include the document name.
